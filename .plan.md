# Plan: Apply ZEUS-X Hero Design to Morphiic

## Context
The user wants to apply the ZEUS-X storm-themed hero design (rain effects, lightning arcs, large wordmark, product stage with side cards, and an about band) to the Morphiic AI Data Transformation Engine landing page. The design will be adapted to use Morphiic's existing cyan accent palette and brand identity.

## Design Decisions
- **Accent color**: Keep Morphiic's cyan (#22D3EE) palette
- **Display font**: Add "Archivo Expanded" from Google Fonts for the wordmark
- **About band**: Add a new band section below the hero (between Hero and Overview)

## Files to Modify

### 1. `index.html` — Add Archivo Expanded font
- Add `Archivo+Expanded:wght@300;500;700` to the Google Fonts `<link>` href

### 2. `tailwind.config.js` — Register font
- Add `'display-wide': ['"Archivo Expanded"', 'system-ui', 'sans-serif']` to `fontFamily`

### 3. `src/components/hero/Hero.tsx` — Complete rewrite
Adapt the ZEUS-X design structure:
- **Storm backdrop**: Radial gradients using base-900/base-800/base-950 colors
- **Rain effect**: 26 animated vertical lines with staggered delays (same technique)
- **Storm flash**: White overlay with `stormFlash` keyframe animation
- **Wordmark**: "MORPHIIC" in Archivo Expanded with `-webkit-text-stroke` outline, lightning arc SVG between "MORPH" and "IIC" (or a data-flow icon)
- **Product stage** (replaces generator):
  - Left card: "Enterprise Sources" card with data source count
  - Right card: "AI Engine" label with lightning icon
  - Center: Styled engine body (clip-path polygon) containing the DataFlowVisualizer
  - "EXPLORE" circular button (left side, like ORDER)
  - "99.9% UPTIME" badge (right side, like 10HR badge)
- **Animations**: framer-motion entrance animations for all elements

### 4. `src/components/hero/DataFlowVisualizer.tsx` — Style adjustments
- Update container styling to fit within the new engine body clip-path
- Reduce size/padding to fit the product stage layout
- Keep the rotating rings, SVG connectors, and pipeline stages

### 5. `src/components/hero/HeroAboutBand.tsx` — New file
About band section directly below the hero:
- **Left card**: "AI-POWERED" card with a data transformation icon and "Zero Manual" text
- **Center**: "ABOUT MORPHIIC" eyebrow + heading about sustainable data transformation
- **Right card**: "PIPELINE STAGES" gauge showing 7 stages with an animated SVG circle gauge
- Background: `bg-[#080A0D]` with `border-t border-base-400/40`

### 6. `src/pages/Home.tsx` — Import HeroAboutBand
- Import `HeroAboutBand` from `@/components/hero/HeroAboutBand`
- Insert `<HeroAboutBand />` after `<Hero />` and before `<Overview />`
